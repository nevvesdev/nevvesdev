## Projetos em destaque

- **[guardian-api](https://github.com/nevvesdev/guardian-api):** API com autenticação JWT (access e refresh token), controle de acesso por papéis (RBAC), auditoria de acessos e rate limiting com Redis.
- **[open-finance-consent](https://github.com/nevvesdev/open-finance-consent):** gestão do ciclo de vida de consentimento do Open Finance Brasil, com Arquitetura Hexagonal, OAuth2 Resource Server (escopos), Transactional Outbox e testes com Testcontainers.
- **[notification-hub](https://github.com/nevvesdev/notification-hub):** microsserviço de notificações orientado a eventos, consumindo Kafka, com Resilience4j, Flyway e testes de integração com Testcontainers.
- **[cqrs-pattern](https://github.com/nevvesdev/cqrs-pattern):** CQRS e Transactional Outbox em dois microsserviços, com publicação de eventos no Kafka por polling (simulando CDC).
- **[event-driven-banking](https://github.com/nevvesdev/event-driven-banking):** sistema bancário com 3 microsserviços (conta, transferência e notificação) comunicando via REST e Kafka, com idempotência e CI com GitHub Actions.
- **[settlement-engine](https://github.com/nevvesdev/settlement-engine):** API de liquidação de transações com máquina de estados, idempotência por ID externo e integridade garantida por constraints no banco.
