## Sobre mim

Há mais de dois anos atuo em operações de uma grande empresa do setor sucroenergético, lidando com faturamento, controle fiscal, indicadores e rotinas que não podem parar. Nesse contexto aprendi a olhar para processo com atenção aos dados: onde ele quebra, onde gera retrabalho e o que medir para saber se melhorou.

Hoje levo esse olhar para os dados: automatizo rotinas com Python, transformo planilhas e sistemas em indicadores no Power BI e construo pipelines e alertas que avisam antes que o problema vire prejuízo. Antes disso, desenvolvi sistemas backend em Java e Spring Boot, que aparecem na seção de base técnica.

## Projetos em destaque

**Dados e processos** *(em construção, com dados simulados)*

- **Pipeline de dados operacionais:** ingestão, limpeza e modelagem de dados de uma operação sucroenergética, com Python, pandas, PostgreSQL e Docker.
- **Dashboard de cadeia de suprimentos:** indicadores de processo em Power BI, com DAX, sobre dados simulados.
- **Monitoramento de KPIs com alertas:** cálculo de indicadores agendado com APScheduler e SQLAlchemy, com alertas quando há desvio.

**Base técnica (Java e Spring Boot)**

- **[guardian-api](https://github.com/nevvesdev/guardian-api):** API com autenticação JWT (access e refresh token), RBAC, auditoria de acessos e rate limiting com Redis. *(concluído)*
- **[open-finance-consent](https://github.com/nevvesdev/open-finance-consent):** gestão do ciclo de vida de consentimentos do Open Finance Brasil, com Arquitetura Hexagonal, OAuth2 Resource Server com escopos, Transactional Outbox e Testcontainers. *(concluído)*
- **[notification-hub](https://github.com/nevvesdev/notification-hub):** microsserviço de notificações orientado a eventos, consumindo Kafka, com Resilience4j, Flyway e testes de integração com Testcontainers. *(concluído)*
- **[cqrs-pattern](https://github.com/nevvesdev/cqrs-pattern):** CQRS e Transactional Outbox em dois microsserviços, com publicação de eventos no Kafka por polling (simulando CDC). *(concluído)*
- **[distributed-cache](https://github.com/nevvesdev/distributed-cache):** serviço de consulta de saldo e limite de contas com Redis no padrão Cache-Aside. *(concluído)*
- **[fx-currency-exchange](https://github.com/nevvesdev/fx-currency-exchange):** aplicação de câmbio e taxas de moedas, pensada para casos de uso de fintechs e bancos digitais, com arquitetura em portas e adaptadores. *(concluído)*
- **[alcada](https://github.com/nevvesdev/alcada):** serviço de aprovação e gestão de linhas de crédito, com Saga orquestrada e compensações, eventos via outbox e requisições idempotentes. *(concluído)*
- **[event-driven-banking](https://github.com/nevvesdev/event-driven-banking):** sistema bancário com três microsserviços (conta, transferência e notificação) comunicando-se via REST e Kafka, com idempotência e CI no GitHub Actions. *(concluído)*
- **[financeflow](https://github.com/nevvesdev/financeflow):** painel de controle financeiro pessoal com lançamentos, categorias, contas a vencer e alertas agendados. *(em andamento)*
